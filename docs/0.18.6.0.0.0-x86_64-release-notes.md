# AROSA SDK 0.18.6.0.0.0 — x86_64 experimental developer release

**Author of original AROSA work: DaniloS.**

This historical, binary-only developer SDK allows applications to consume AROSA capability/service interfaces without providing the private AROSA source tree. It includes compiled Pascal units/objects, native AROS bridge libraries, SHA-256 manifest and authentic ThorVG/Brotli/tinf/NanoSVG notices.

## Verified functionality (23 November 2026)

- Historical independent AFileManager x86_64 build/link succeeded and its graphical UI launched on AROS.
- A separate **HelloAROSA** SDK sample compiled and linked using the real AROS x86_64 cross compiler and `collect-aros`. Its executable was identified as **ELF 64-bit, x86-64, AROS**. **The HelloAROSA executable itself has not yet been run inside AROS.**
- The released licensed archive passed ZIP CRC and full SHA-256 manifest verification: **482 entries, 481 checked hashes, 473 preserved compiled artifacts**, and six third-party notice files.
- ThorVG and webfont library member inventories matched the historical source compilation layout.
- Original AROSA components copyright **DaniloS**. Upstream licensors retain rights in third-party components. See [SDK Developer License](../SDK-LICENSE.md) and the bundled `THIRD-PARTY-NOTICES/` files.

## Requirements and limitations

- Requires matching AROS x86_64 FPC/RTL, target toolchain and compatible AROSA runtime/services; SDK ZIP **does not include a complete AROS toolchain or an operating-system runtime**.
- Main SDK guide: [README](../README.md); usage examples, cross-build script and archive inspector: [examples/](../examples/README.md).
- AFileManager source: https://github.com/danilos/AFileManager (separate MPL-2.0 license).
- General compatibility, file operations, long-running stability and HelloAROSA runtime execution have **not** been exhaustively verified.
- **i386 archive is not part of this x86_64 release**; support remains experimental, and i386 GUI startup is unverified.
